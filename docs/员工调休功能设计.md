# 员工调休功能设计文档

## 一、功能概述

为系统新增员工调休功能，放在"成本管理>员工调休"菜单下。该功能以员工薪资表为基准表，实时统计显示员工的调休数据，数据来源于加班管理模块。

**需求要点**：
- 数据展示：员工名称、总调休、待确认调休、已确认调休、已使用调休
- 搜索条件：仅支持员工名称模糊搜索
- 数据来源：加班时长即为调休时长，来源于 `biz_overtime_record` 表
- 已使用调休需要新建调休使用记录表

## 二、数据库设计

### 1. 调休使用记录表（biz_leave_record）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | varchar(36) | 主键ID |
| staff_id | varchar(36) | 员工ID |
| staff_name | varchar(100) | 员工姓名（冗余存储） |
| leave_date | date | 调休日期 |
| leave_hours | decimal(4,1) | 调休时长（小时） |
| leave_reason | varchar(500) | 调休原因 |
| del_flag | int(1) | 删除状态（0:正常, 1:已删除） |
| create_by | varchar(50) | 创建人 |
| create_time | datetime | 创建时间 |
| update_by | varchar(50) | 更新人 |
| update_time | datetime | 更新时间 |

索引：`idx_staff_date` (staff_id, leave_date)

**说明**：调休录入即生效，无需审批流程

### 2. 建表 SQL

```sql
CREATE TABLE IF NOT EXISTS `biz_leave_record` (
  `id` varchar(36) NOT NULL COMMENT '主键ID',
  `staff_id` varchar(36) NOT NULL COMMENT '员工ID',
  `staff_name` varchar(100) DEFAULT NULL COMMENT '员工姓名（冗余存储）',
  `leave_date` date NOT NULL COMMENT '调休日期',
  `leave_hours` decimal(4,1) NOT NULL COMMENT '调休时长（小时）',
  `leave_reason` varchar(500) DEFAULT NULL COMMENT '调休原因',
  `del_flag` int(1) DEFAULT 0 COMMENT '删除状态',
  `create_by` varchar(50) DEFAULT NULL COMMENT '创建人',
  `create_time` datetime DEFAULT NULL COMMENT '创建时间',
  `update_by` varchar(50) DEFAULT NULL COMMENT '更新人',
  `update_time` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_staff_date` (`staff_id`, `leave_date`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='调休使用记录表';
```

## 五、统计 SQL 设计

```sql
-- 员工调休统计（以员工薪资表为基准）
SELECT 
    es.employee_id AS employeeId,
    es.employee_name AS employeeName,
    IFNULL(SUM(CASE WHEN o.del_flag = 0 THEN o.overtime_hours ELSE 0 END), 0) AS totalOvertimeHours,
    IFNULL(SUM(CASE WHEN o.del_flag = 0 AND o.confirm_status = 0 THEN o.overtime_hours ELSE 0 END), 0) AS pendingOvertimeHours,
    IFNULL(SUM(CASE WHEN o.del_flag = 0 AND o.confirm_status = 1 THEN o.overtime_hours ELSE 0 END), 0) AS confirmedOvertimeHours,
    IFNULL((
        SELECT SUM(l.leave_hours) 
        FROM biz_leave_record l 
        WHERE l.del_flag = 0 AND l.staff_id = es.employee_id
    ), 0) AS usedLeaveHours
FROM biz_employee_salary es
LEFT JOIN biz_overtime_record o ON es.employee_id = o.staff_id
WHERE es.del_flag = 0
AND es.employee_name LIKE CONCAT('%', #{employeeName}, '%') -- 可选搜索条件
GROUP BY es.employee_id, es.employee_name
ORDER BY es.employee_name
```

## 六、关键业务规则

### 1. 统计逻辑

| 字段 | 计算规则 |
|------|----------|
| 总调休 | 所有加班记录时长（不限确认状态） |
| 待确认调休 | 确认状态=0的加班时长 |
| 已确认调休 | 确认状态=1的加班时长 |
| 已使用调休 | 调休记录时长（录入即生效） |
| 剩余调休 | 已确认 - 已使用（VO中计算） |

### 2. 数据校验

- 调休时长不能超过剩余调休（已确认 - 已使用）
- 调休时长最多一位小数
